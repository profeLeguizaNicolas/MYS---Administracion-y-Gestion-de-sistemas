MYS - Administración y Gestión de Sistemas.

Los alumnos deberán investigar, practicar y exponer de manera práctica los siguientes puntos relacionados con instalación, configuración y administración de sistemas operativos:

input
  1. Crear un dispositivo booteable utilizando Rufus junto con Hiren's BootCD PE para tareas de recuperación de cuentas de Windows (Cambio de Password)
  2. Crear un dispositivo booteable de Windows 11, realizar su instalación completa, activarlo y configurar el sistema para obtener el mejor rendimiento posible durante el arranque y funcionamiento general.
  3. Obtener una imagen ISO de Microsoft Office, instalar el paquete y realizar su activación.
  4. Crear y administrar diferentes tipos de cuentas de usuario de Windows.
  5. Crear un dispositivo multibooteable utilizando Ventoy que incorpore Hiren's BootCD PE, Windows 11, Linux Mint y Microsoft Office.

La evaluación tendrá en cuenta la correcta realización práctica, la organización de las herrmientas utilizadas, el procedimiento aplicado y la explicación técnica de cada tarea realizada.
